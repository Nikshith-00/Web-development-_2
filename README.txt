TASK 02 - STOPWATCH WEB APPLICATION
======================================

Created for Nikshith Jampala.

How to run in VS Code:
1. Extract the ZIP file.
2. Open the Task-02-Stopwatch-Nikshith folder in VS Code.
3. Open index.html.
4. Right-click index.html -> Open with Live Server.
   If Live Server is not installed, install the "Live Server" extension.
5. Test Start, Pause, Lap and Reset.

Features:
- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Lap time recording
- Lap counter
- Responsive design
- Fixed navigation
- Smooth scrolling
- HTML + CSS + JavaScript
